## 💻 6. Local Installation

Project ko apne computer par chalane ke do asaan tareeqe hain.

### Method 1: Direct Browser

1. Project folder open karein.
2. `index.html` par double-click karein.
3. Website aapke default browser mein open ho jayegi.

### Method 2: Python Local Server

Terminal ya CMD mein project folder open karke ye command chalayein:

```bash
python -m http.server 8000
```

Ab browser mein ye address open karein:

```text
http://localhost:8000
```

## 🚀 7. GitHub Pages Hosting

Website ko GitHub par publish karne ke liye ye steps follow karein.

### Step 1: Git Initialize Karein

```bash
git init
git add .
git commit -m "Initial commit - Jalees-e-Hikmat"
git branch -M main
```

### Step 2: GitHub Repository Banayein

GitHub par `jalees-e-hikmat` naam se repository create karein.

Repository:

https://github.com/feelsoof123/jalees-e-hikmat

### Step 3: Project Upload Karein

```bash
git remote add origin https://github.com/feelsoof123/jalees-e-hikmat.git
git push -u origin main
```

### Step 4: GitHub Pages Enable Karein

1. GitHub repository open karein.
2. Settings mein jayein.
3. Pages option select karein.
4. Build and Deployment mein `Deploy from a branch` select karein.
5. Branch mein `main` select karein.
6. Folder mein `/(root)` select karein.
7. Save par click karein.

### 🎉 Live Website

https://feelsoof123.github.io/jalees-e-hikmat/
